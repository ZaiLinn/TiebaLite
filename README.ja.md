## 📖 はじめに

TiebaLite は**非公式**の百度貼吧 Android クライアントです。Kotlin で記述され、UI は Jetpack Compose で構築されています。**Android 5.0 から Android 16** までの超長期幅広いデバイスに対応し、16KB ページアライメントにも完全対応。本質は百度貼吧 API のリバースエンジニアリング実装であり、中核となる閲覧体験を犠牲にすることなく、最も軽量でクリーンな貼吧クライアントを提供することを目標としています。

> **⚠️ 声明：** 本ソフトウェアおよびソースコードは学習・交流のみを目的とし、商業利用は厳禁です。百度社とは一切関係ありません。

## 🆕 v4.0.60 — アルバムが閉じない問題の修正（issue #1 の根本原因）

> ### 🖼️ 選択の確認後に回复へ戻るように
> 「画像は挿入されるがアルバムページが閉じない」問題を修正——issue #1 当初の症状で、実機・エミュレータの両方で再現していました：画像選択 UI が 1 回のタップで 2 回起動していました。グローバルイベントバスの購読が不安定な effect key を使っており、再構成時に新旧のコレクターが重なり、同じイベントで起動が 2 回呼ばれて選択 UI が 2 つ重なります。確認すると下の空インスタンスが現れていました。バス購読を常駐単一コレクターに改め、起動に再入防止を追加しました。

## 🆕 v4.0.59 — 初回選択の失敗修正（issue #1 続報）

> ### 🖼️ 一回目の選択で成功するように
> 実機で「一回目の画像選択が必ず失敗し、二回目で成功する」問題を修正（Redmi K70 / HyperOS で実測、10 回中 5 回再現）：選択器を開くと App がバックグラウンドに退き、ROM がプロセスを回收または Activity を再構築すると、パネルのリクエスト id が変わり、古い id を持つ結果がフィルタで破棄されていました。全体選択イベントの消費者は一つのみなので、id フィルタを撤去しました。
> v4.0.58 はエミュレータ（Android 12）の選択器未解決問題を修正、本版は実機の初回選択失敗を修正します。

## 🆕 v4.0.58 — 画像選択器の互換性修正

> ### 🖼️ どこでも画像を追加できるように
> Android 12 の一部 ROM（MuMu エミュレータ等）で「画像を追加できない」問題を修正：これらの ROM は写真選択器モジュールを同梱していますが、picker activity が実際には解決できず、タップしても無反応でした。起動前に intent が解決可能か確認し、不可能な場合は内蔵選択器にフォールバックします。
> 実機（Android 13+）のシステム写真選択器には影響ありません。

## 🆕 v4.0.0.34 — 定期チェックインのクロック较正

> ### ⏰ 日跨ぎ顺延メカニズム
> 従来定期チェックインが偶発的に漏れる根本原因は `initAutoSign` の时刻判定ロジックに：
> - 今日の目標时刻が既に過ぎた → そのままアラームを设定しない（漏签）
> - アラーム発火后の reschedule がミリ秒级误差で「既に过ぎた」と判定 → 翌日の予約をしなくなる
>
> **修正方針：**
> - 秒 / ミリ秒をゼロクリアし、判定误差を解消
> - 目標时刻が過ぎていれば翌日に顺延、アラームは常に有効
> - 3 箇所の呼び出しをカバー：App 起動 / アラーム reschedule / 起动时再起動
>
> これからチェックインは时间通りに発火し、全日候で安定稼働。

## 🛠️ ビルド说明 / Build Instructions

### 环境要件 / Prerequisites

- **JDK 17+**
- **Android SDK** with **compileSdk 34**
- Android Studio（推奨 / Recommended）

### 署名设定 / Signing Configuration

Release 署名用に `keystore.properties` ファイルを作成：

Create a `keystore.properties` file for release signing:

```properties
storeFile=your_keystore_file.jks
storePassword=your_store_password
keyAlias=your_key_alias
keyPassword=your_key_password
```

> ⚠️ **注意 / Note:** `keystore.properties` ファイルはバージョン管理システムにコミットしないでください。/ Do NOT commit the `keystore.properties` file to version control.

### ビルドコマンド / Build Commands

```bash
# デバッグビルド / Debug Build
./gradlew assembleDebug

# リリースビルド / Release Build
./gradlew assembleRelease
```

ビルド产物は `app/build/outputs/apk/` ディレクトリに出力されます。

Build outputs are located in the `app/build/outputs/apk/` directory.
